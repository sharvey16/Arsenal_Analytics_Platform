# Arsenal Football Club Analytics Platform

## Overview

The Arsenal Football Club Analytics Platform is an end-to-end football analytics project built using StatsBomb Open Data.

The project analyzes Arsenal FC's 2015/2016 Premier League season through a complete analytics pipeline including:

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI

The goal was to develop a professional sports analytics workflow capable of transforming raw football event data into actionable insights and interactive dashboards.

## Key Findings

### Player Performance

- Mesut Özil led Arsenal with 8,413 total events
- Mesut Özil completed 2,511 passes
- Alexis Sánchez attempted 111 shots
- Olivier Giroud scored 16 goals
- Olivier Giroud generated 13.02 xG

### Team Performance

- Matches Played: 38
- Wins: 20
- Draws: 11
- Losses: 7
- Points: 71
- Goals Scored: 65
- Goals Conceded: 36
- Goal Difference: 29

### Home vs Away

- Arsenal earned 40 points at home
- Arsenal earned 31 points away
- Arsenal scored more goals away from home
- Arsenal conceded only 11 goals at home compared to 25 away
